**Sky Courier — The Island Run**: a chase-view flight game over a chain of islands. You are the courier pilot of the twin-prop SKY-7. Take off from the home runway, thread all six golden rings over sea and islands, then bring her home and land on the runway before the fuel runs dry. Throttle and bank discipline decide everything: climb too steep and you stall, bank too hard and you bleed speed, dawdle and the tanks run dry over open water.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — every file the game loads sits under `game/`.
